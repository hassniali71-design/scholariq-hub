# مجلد صور الغلاف للمدرسين

ضع هنا صور الغلاف باسم `{cover_image_key}.jpg` (أو `.png`/`.webp`).

مثلاً: لو المدرس عنده `cover_image_key = "math-1"`, ضع ملف `math-1.jpg` هنا.
سيتم عرضه تلقائياً في `SubjectRoomHeader` (teacher.index, teacher.schedule, إلخ).

لو الملف غير موجود، يعرض placeholder ملوّن بـ `theme.primary`.
