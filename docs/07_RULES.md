# القواعد الصارمة

- **لا تغيّر أي تصميم بصري** (ألوان، خطوط، تخطيط) إلا لو طُلب صراحة — العمل الحالي
  كله Refactor أو إضافة وظيفية فوق شكل ثابت بالفعل ومعتمد.
- **حافظ على RTL/العربي في كل مكان** — `dir="rtl"` و`lang="ar"` أساسيان في هذا
  المنتج.
- **لا تكسر `bun run dev` بعد أي تعديل** — تأكد بتشغيله قبل ما تعتبر المهمة خلصت.
  لو انقطع الشغل في أي لحظة (تحقق أو حد الرسائل)، لازم المشروع يفضل في حالة قابلة
  للتشغيل والبناء، مش نص شغلانة.
- **لا تضف مكتبات جديدة بدون داعي واضح** — الستاك الحالي (`recharts`,
  `lucide-react`, `shadcn/ui`) كافي لمعظم الاحتياجات المتوقعة.
